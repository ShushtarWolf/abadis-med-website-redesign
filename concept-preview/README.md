# Abadis Suction Bag Concept Preview

This directory contains the rendered Nuxt concept preview recovered from the Netlify deployment `abadis-suction-bag-preview.netlify.app`.

The page is intentionally kept as a static deployment artifact for review and migration planning. It is not yet the production Nuxt 4 application and does not activate form submission or replace the existing WordPress URLs.
