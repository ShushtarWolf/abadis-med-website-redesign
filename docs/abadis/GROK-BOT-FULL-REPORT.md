## 0. Standing rules (must follow)

File: `.cursor/rules/abadis.mdc`

1. Work **ONLY** on `siamak/redesign`. Start with `git fetch && git checkout siamak/redesign && git pull --no-rebase origin siamak/redesign`.
2. **Never** push to `main`. Never force-push. Never rewrite pushed history / others’ commits. Merge remote with `--no-rebase`.
3. Delivery to `main` is via human-merged PR only.
4. **Generator vs hand-edit:**
   - Generated: `python3 tools/redesign/build.py [group]` — groups include `home products about dealers calculator csr contact customers experiences downloads install faq careers posts i18n`.
   - **Home** (`site/index.html`) is generated by `tools/redesign/pages_home.py` — do **not** hand-edit it.
   - Hand-built: `site/products/suction-bag/index.html`; `site/csr/index.html` and `site/contact/index.html` have `<!-- phase2:… -->` blocks rewritten by generator.
   - Shared chrome: `tools/redesign/layout.py`. CSS: `site/assets/css/site.css` (+ `home.css` for home). JS: `site/assets/js/site.js`.
   - **Do not run** legacy `tools/build_site.py`.
5. Brand: Kalameh only; teals `#066163 #05686b #015F61 #0e7475 #087673`; mint `#e8f3f3` / `#f3fafa`. No yellow/lime on teal. No gore. No mouse-follow effects.
6. Themes: `light` / `dark` / `noir` via `data-theme` + `localStorage["abadis-theme"]` + `?theme=`.
7. Content: verbatim from abadis-med.com (http REST / uploads work; Wayback fallback). Do not invent copy, specs, names, certs.
8. Every page keeps `<meta name="robots" content="noindex,nofollow">` until deliberate launch task.
9. After rebuild, check `git diff --stat site/` for unexpected image losses (img cache).
10. Persian typography: read `docs/persian-typography.md` before typography work.

## 1. What this project is

Static redesign of **مخازن طبی آبادیس** (Abadis Med) — hospital suction-bag / infection-control manufacturer.  
Static site in `site/`; Python generator in `tools/redesign/`; data from WP REST + Wayback crawls in `tools/redesign/data/`.

**Preview note:** GitHub Pages environment allows **only `main`**. Pushing `siamak/redesign` with `pages.yml` fails until Settings → Environments → github-pages adds branch `siamak/redesign`. Local preview: `python3 -m http.server 8080 --directory site`.
